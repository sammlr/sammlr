# Source Assets

Dieser Ordner enthaelt offizielle Originalquellen fuer Sammlr-Masterassets.

Regeln:

- Offizielle Quellen haben Vorrang vor alten Masterdateien.
- Quellen werden nicht frei nachgezeichnet oder interpretiert.
- Wenn eine Quelle nicht exakt reproduzierbar ist, wird kein neues Master erstellt.

## VfL-Osnabrueck-Albumbranding

`vfl_official_logo_source.png` ist die offizielle Quelle fuer das VfL-Osnabrueck-Albumbranding innerhalb von Sammlr. Die Geometrie, Proportionen, Winkel, Buchstabenformen und Abstaende duerfen nicht interpretiert oder veraendert werden. Alle zukuenftigen VfL-Master-Assets muessen auf dieser Quelle basieren.

Fuer das VfL-Logo gilt zusaetzlich:

- Niemals das Logo nachzeichnen.
- Niemals Buchstaben oder Rauten rekonstruieren.
- Niemals Proportionen interpretieren.
- Falls eine SVG benoetigt wird, darf sie ausschliesslich durch Vektorisierung von `vfl_official_logo_source.png` entstehen.
- Eine veredelte Sammlr-Master-SVG ist erst nach erfolgreicher Vektorisierung dieser PNG zulaessig.
- Nicht die Form wird gestaltet. Nur das Material.
