# Trophy-Zwischenschritt

Status:
Aktiv

Bis zur Layout-Freigabe der kompletten Trophy-Familie werden alle Trophäen ausschließlich aus bestehenden Masterdateien aufgebaut:

- `master_shield_v1`
- `master_header_v1`
- `master_logo_v1` fuer globale Trophäen

Regeln:

- Keine Icons darstellen
- Keine Albumlogos darstellen
- Keine zusätzlichen Grafiken darstellen
- Globale Trophäen erhalten unten ein geprägtes Sammlr-Logo
- Album-Trophäen bleiben unten leer
- Erst nach validierter Größe, Abständen und Layout werden Icons und Albumbrandings wieder eingesetzt
